Por que “requer API”?

O motor de cálculo oficial é uma aplicação Java e não roda num site estático. Para calcular, rode as APIs no seu computador (ou num servidor) e informe o endereço na aba Calculadora:

git clone --recurse-submodules https://github.com/RafaelNicolauiOS/calculadora-rtc-mcp.git
cd calculadora-rtc-mcp
./scripts/build.sh
./scripts/run.sh

O run.sh sobe as três APIs e um proxy em http://localhost:8079 que libera o acesso a partir deste site.
